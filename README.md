# 🌐 Social Media Links Page

A simple social media links page built with HTML and CSS.

This project was developed during the **HTML5 and CSS3 course** by Professor Gustavo Guanabara from Curso em Vídeo.

🔗 Live Demo  
https://devdiegorosa.github.io/projeto-redes-sociais/

---

## 👨‍💻 About the Project

This project is a simple webpage that displays links to different social media platforms.

The goal of the project was to practice the fundamentals of HTML and CSS while building a clean and functional page with clickable links.

---

## 🚀 Features

- Social media links
- Simple and clean layout
- Responsive design
- Profile image and user information
